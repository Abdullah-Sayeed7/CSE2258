# CodeQuiz - Web Technology Mini Project (CSE2258)

A simple quiz website built for our Web Technology course. It lets students test their basic programming knowledge across 6 topics with timed quizzes, input validation, and automatic score calculation.

## Topics Covered
- **Languages & Topics**: Python, C, C++, Java, HTML, CSS
- **Difficulty Modes**:
  - **Easy**: 10 questions (20-minute countdown)
  - **Hard**: 15 questions (30-minute countdown)

## Features
- **Student Verification**: Validates student name, college email, and a 12-character university roll number before submission.
- **Countdown Timer**: Displays remaining time, alerts when under 2 minutes remain, and auto-submits if time runs out.
- **Question Validation**: Highlights unanswered questions in red and blocks empty submissions.
- **Instant Results**: Calculates final score, displays percentage feedback, and generates a personalized scorecard.
- **Accidental Exit Warning**: Prompts a confirmation if you try to leave or refresh mid-quiz.
